# Lessons the trader has learned (updated 2026-11-06, simplified to GLD/SPY/QQQ)

- Do not stack the same bet twice: one position per instrument, add to it deliberately instead of buying the same thing every cycle.
- Keep a new position small at first (about 2-4% of equity) and only add when the trade is working.
- When an order fails, find out why before trying again; repeating the same failing order is a mistake.
