# Lessons the trader has learned (updated 2026-11-05)

- Prefer gold mining equities (GDX, NEM) over physical gold instruments (GLD, IAU, PAXG/USD) when miners exhibit relative strength.
- Crypto tokens like PAXG/USD start down due to spread and fees (-1.15% move across 4 trades), so avoid scaling repeatedly into PAXG/USD without clear breakout momentum.
- Do not stack redundant exposures across GLD, IAU, and PAXG/USD at the same time since they track the same underlying risk.
- When sell order errors occur (such as 4 failed AAPL sells), correct the order parameters immediately rather than leaving an unwanted position open.
- Limit cumulative position size in any single instrument to owner guidelines (2-4% equity starter) instead of building a 7.7% position in a declining asset.
